  How the New Strategy Breaks the Loop

  The subagent-optimized strategy I created eliminates manual reviews entirely and replaces them with automated gates:

  OLD WORKFLOW (Stuck in loop):
    You: "Exhaustive review" [vague]
    Claude: Explores, spins up agents
    You: Waits 5 min, gets impatient, interrupts
    [Repeat 7 times]

  NEW WORKFLOW (Automated):
    You: Write plan doc (offline, no rushing)
    Main agent: Generate task JSON (2 turns, minimal tokens)
    Main agent: Execute tasks with subagents (hands-off)
    Subagent 1: Scan codebase → Report files (isolated, fast, no interruption point)
    Subagent 2: Implement task 1 → Run test gate (isolated, fast)
    Subagent 3: Implement task 2 → Run test gate (isolated, fast)
    Main agent: Report summary (you see only final results)
    ✅ No review loop, no interruptions

  Why this works:
  1. You do the planning work yourself (offline, no pressure)
  2. Main agent only orchestrates (minimal time, minimal bloat)
  3. Subagents execute isolated tasks (no exploratory phase to watch)
  4. Test gates are automatic (no "waiting for approval")
  5. You see only task completion summaries (no intermediate messiness)

      "fix": "specific action"
    }
  ]

  Do NOT write prose analysis. Return ONLY the JSON array."

  Why it works: Clear format = Claude knows what "done" looks like. Shorter output = you don't interrupt.
