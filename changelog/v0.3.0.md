# v0.3.0 — Migration Hardening & Tools Reorganization

**Release Date:** 2026-02-26
**Breaking:** No (internal restructuring only; CLI commands unchanged)

## Summary

This release delivers robust migration orchestration, reorganizes the internal tools package into logical subpackages, cleans up the test infrastructure, and completes documentation updates. All CLI commands remain unchanged — only internal import paths have moved.

## Added

- **`migration/planner.py`** — Orchestrates `schema_differ` output into sequenced migration plans. Maps diff types to migration templates and orders steps according to the pipeline DAG.
- **`migration/runner.py`** — Executes migration plans with backup/rollback support. Creates timestamped backups before modifications; rolls back atomically on failure. Supports dry-run mode.
- **`tests/conftest.py`** and **`tests/integration/conftest.py`** — Shared pytest fixtures (`repo_root`, `schema_root`, `spec_root`, `canon_root`, `fixtures_root`, `migration_prompts_root`). Centralizes `sys.path` setup.
- **`tests/test_migration_planner.py`** — Tests for migration plan creation, diff-to-template mapping, step ordering, and paradigm shift handling.
- **`tests/test_migration_runner.py`** — Tests for backup creation, rollback on failure, dry-run mode, and transaction boundary grouping.
- **`tests/test_migration_templates.py`** — Tests that all 14 migration templates exist, are readable, non-empty, and contain `{{...}}` placeholders.
- **`tests/fixtures/migration/`** — Test fixtures for migration scenarios.
- **`docs/ops/adr_template_engine.md`** — ADR documenting the decision to keep the Handlebars-style template renderer.
- **`docs/ops/toolkit_update_checklist.md`** — Standard operating procedure for schema, prompt, canonical, and migration template changes.
- **`[tool.pytest.ini_options]`** section in `pyproject.toml` for pytest configuration.

## Changed

- **Tools reorganized into subpackages:**
  - `core/` — errors, registry, trace_types, changelog_parser
  - `validation/` — validate, validators/, all linters (fixtures, seed, docs, quality, hallucination, dependency, forward-replay, traceability, invariants, governance, matrix)
  - `generation/` — prompt_generator, prompt_schema_sync, schema_differ
  - `canonical/` — autofix, integrity, lint, registry
  - `migration/` — planner, runner (new)
- **8 test files renamed** to remove batch-number prefixes (B2/B3/B4) for cleaner naming.
- **`sys.path.insert` removed** from all 28+ test files; centralized in `conftest.py`.
- **All test imports updated** to use new subpackage paths.
- **Documentation updated:** getting_started.md (version), reference.md (test invocation, scope lock), README.md (directory layout), CLAUDE.md (version, import paths, integration test invocation).
