# v0.2.1 - 2026-02-07

### Added
- Seed manifest schema (`schema/seed_manifest.schema.json`) and shared manifest at `spec/common/seed_manifest.json`.
- New CLI commands: `seed-lint` and `docs-lint`.
- `docs_impact` planning field in Step 16 implementation context.

### Changed
- All prompts now require seed manifest ingestion and `seed_refs` population.
- Step 16 prompts now enforce documentation impact planning and review.
- Trinity loop prompts now require a context evaluation step that updates the seed manifest when additional docs (e.g., READMEs/tooling guides) are required.
- Spec changes are now explicitly treated as non-doc changes in the Trinity loop, requiring docs impact planning and updates.
- Trinity loop prompts now reference the enforced `./tools/run_specdev.sh` wrapper for validation and align review guidance with the Step 16 schema.
- Project initialization now creates `spec/common/seed_manifest.json`.
- Documentation policy now supports per-scope README depth via the seed manifest and defaults to no implicit depth.

### Breaking
- Step 00–16 schemas now require `seed_refs`.
