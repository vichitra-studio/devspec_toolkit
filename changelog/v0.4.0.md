# v0.4.0 — Generation Quality Simplification

**Release Date:** 2026-02-27
**Breaking:** Yes

## Summary

This release simplifies `generation_quality` to an `assumptions`-only block and removes the redundant E511 `PLACEHOLDER_SCAN_MISMATCH` validator. A migration script is provided to convert existing artifacts automatically.

## Breaking Changes

- **`generation_quality` reduced to `assumptions`-only.** The following sub-fields have been removed: `preflight_passed`, `evidence_records`, `unresolved_inputs`, `placeholder_scan`, `self_check_results`. The `required` array has also been removed.

## Removed

- **E511 `PLACEHOLDER_SCAN_MISMATCH`** error code and its validator `_check_placeholder_scan_agreement()`. E510 independently catches all placeholder issues.

## Added

- **Migration script:** `python -m specdev_tools.migration.scripts.strip_generation_quality <directory>` — converts old-format `generation_quality` blocks to assumptions-only.

## Migration Guide

- Run `python -m specdev_tools.migration.scripts.strip_generation_quality` on all spec directories and fixture directories.
