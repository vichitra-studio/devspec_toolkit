# Documentation Overview

The AI Spec Driven Development Toolkit separates documentation by audience to keep guidance predictable and easy to maintain.

## Sections
- `developers/` — human-focused onboarding, reference material, workflow overviews, and diagnostics.
- `agents/` — operational contract and manifest for AI or automated contributors.
- `templates/` — shared generic templates (e.g., the unified guide blueprint reused across steps).

## Start Here
1. Developers: open `developers/index.md` and follow the links to `getting_started.md`, `reference.md`, or the workflow guides.
2. Agents: consume `agents/manifest.json` (machine hints) and `agents/agents.md` (detailed protocol).

## Related Assets
- Toolkit overview: `../README.md`
- CLI details: `../tools/README.md`
- Examples: `../example/`
- Tests and fixtures: `../tests/`

## Contributing Improvements
1. Align updates with the structure above (developers vs. agents).
2. Document notable changes in `developers/changelog.md`.
3. Open a PR summarizing the gap addressed and include validation steps.
